Éditeur de motif

Chaque ligne doit lever 1 à N−1 cadres (jamais 0, jamais tous). Les lignes invalides sont en rouge.

Nombre de cadres

Combien de cadres ton métier compte. Modifier cette valeur reconfigure toute l'app (pilotage, motifs, calibration, mappage). Les motifs existants restent compatibles si leur taille est ≤ au nouveau nombre.

Pins physiques disponibles selon le nombre : D9, D10, D11, D12, D5, D6, D8, D3. La sécurité métier devient « 1 à N−1 cadres levés simultanément ».

Tassage entre duites

Délai pendant lequel tous les cadres descendent entre deux duites, permettant de tasser la trame avec le peigne avant que le motif suivant ne se lève.

2500 ms
0 ms = pas de tassage (ancien comportement). Recommandé : 2000-3000 ms.

Maintien des cadres en l'air

Temps minimal pendant lequel les cadres restent levés après chaque duite. En mode classique, la commande suivante est bloquée pendant ce délai. En mode auto, ce délai s'applique aussi (en plus de l'intervalle auto si plus long).

2500 ms
Exemple : 2500 ms laisse le temps de passer la navette avant la duite suivante.

Calibration servo (zéro et amplitude par cadre)

Plage des servos : 0° à 270°. Règle pour chaque cadre la position basse (cadre relâché, navette passe pas) et la position haute (cadre levé, foule ouverte). Bouton Test envoie le servo à cette position immédiatement pour vérifier visuellement.

Test matrice LED

Allume toutes les LED de la matrice 12×8 du UNO Q pendant 1.5 s, puis revient à l'affichage normal. Si tu ne vois rien s'allumer, le pilote LED est cassé ou le MCU ne reçoit pas la commande.

Test physique des sorties

Clique sur un bouton pour faire bouger le servo branché sur ce pin physique du MCU (cycle haut → maintien 1s → bas). Note quel cadre physique bouge pour identifier le câblage réel.

Mappage cadre logique → sortie physique

Pour chaque cadre logique (utilisé partout dans l'UI : Plan de tissage, Tissage, Pilotage), choisis sur quelle sortie physique du MCU il est câblé. Le mappage doit être une permutation (chaque sortie utilisée une seule fois).

Plan de tissage (remettage + plan de levée + aperçu tissu)
